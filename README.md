# IntelStom — демонстрационный сайт

Демонстрационный макет сайта стоматологии **IntelStom** (Екатеринбург, микрорайон Светлый, 2).

**Это не официальный сайт клиники.** Проект предназначен для согласования дизайна с потенциальным заказчиком.

## Что находится в репозитории

- `index.html` — **полный сайт в одном файле**, с CSS, JavaScript, логотипом и всеми **30 фотографиями**, встроенными непосредственно в HTML в виде data URL.
- Поиск и фильтры направлений лечения, адаптивная галерея, блок контактов и интерактивная 3D-схема зуба на Three.js.
- Фото и логотип подготовлены из предоставленного для проекта архива; в HTML они оптимизированы для веба.
- Шрифт Onest и 3D-библиотека Three.js загружаются из внешних CDN — для их работы нужен интернет.

Отдельная папка с изображениями для запуска **не требуется**.

## Включение GitHub Pages

В этом репозитории откройте **Settings → Pages**.

1. В блоке **Build and deployment** выберите **Deploy from a branch**.
2. Укажите ветку `main` и папку `/(root)`.
3. Нажмите **Save** и дождитесь успешного статуса публикации.

Предполагаемый публичный адрес:
https://maripetrova29091996lev-ai.github.io/intelstom-site/
